# Federated Pooling Plan

## Site-Level Workflow

Each CLIF site runs the same project scripts locally against its own CLIF tables and local exposure inputs.

Buddy-test sites should start from the repository root and run:

```r
Rscript code/run_site_analysis.R
```

## Shared Estimate

The primary pooled DLNM effect is the log relative risk for the 95th percentile `tmax` contrast versus the site-specific reference temperature.

Primary model:

- quasi-Poisson DLNM
- all-season daily OHCA ICU admission counts
- county-linked `tmax`
- humidity adjusted
- median and MRT reference specifications
- lag `0-5`

Sensitivity models:

- humidity plus county-year `no2` and `pm25`
- calendar-time spline sensitivity using 3, 4, and 6 df per year
- subgroup-specific estimates by age, sex, and race
- OHCA-per-ICU-admission-rate DLNMs using total ICU admissions per day as the denominator
- time-stratified case-crossover DLNMs

The 72-hour ICU analyses estimate whether admission-day temperature and humidity are associated with:

- assignment to structured 72-hour phenotype.
- 72-hour competing risk of awake/extubated recovery versus death.

Primary 72-hour models adjust for demographics. Sensitivity models additionally adjust for POA OHCA mechanism.

## Coordinating Center Workflow

The coordinating center places all site `*_dlnm_site_estimates.csv` files in:

```text
output/final/federated_exports
```

Then run:

```r
Rscript code/post_processing/90_pool_federated_results.R
```

This writes:

- `output/final/federated_pooled/all_site_dlnm_estimates.csv`
- `output/final/federated_pooled/pooled_dlnm_random_effects_results.csv`
- `output/final/federated_pooled/all_site_dlnm_curves.csv`
- `output/final/federated_pooled/pooled_dlnm_random_effects_curves.csv`

## Current Pooling Method

The current pooling script uses DerSimonian-Laird random-effects meta-analysis on scalar site-level log relative risks.

This is intentionally simple and easy for all sites to export. A more advanced second-stage DLNM pooling approach can be added later by exporting reduced crossbasis coefficients and variance-covariance matrices from each site.

For supplemental DLNM curves, each site exports aggregate curve points with log relative risk and standard error. The coordinating-center script performs pointwise DerSimonian-Laird pooling at each temperature value. This creates a CLIF-wide curve without sharing row-level data. Temperatures outside a site's observed prediction range are not contributed by that site, so `k_sites` can vary across the curve tails.

The site export also includes reduced cumulative exposure-response coefficient vectors and variance-covariance matrices from `dlnm::crossreduce()`. These files support a future multivariate meta-analysis of the DLNM curve shape, which is statistically preferable to pointwise pooling when enough sites contribute compatible model bases.

Each site also exports figure PNGs under `output/final/federated_exports/figures/`. These include site-level DLNM figures, lag-30 diagnostics, OHCA-rate time series, and 72-hour phenotype figures so the coordinating center can visually inspect site-specific patterns.

The figure exports are for visual QC and site-specific review. The underlying aggregate CSVs should be used for pooled analyses.
