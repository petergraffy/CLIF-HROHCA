# Archived Scripts

These scripts are retained for provenance from earlier analytic versions but are not part of the current site-facing workflow.

The current analytic flow is:

1. DLNM models for OHCA ICU admissions.
2. Structured 72-hour ICU phenotypes.
3. Multinomial phenotype assignment and 72-hour competing-risk models.
4. Aggregate federated export.

Sites should run `code/run_site_analysis.R`; archived scripts should not be needed for routine site execution.
